工程型 · 交叉学科（AI + 出行/交通）

AeroRec · 出行智能推荐中台

开源、可复现的出行场景智能推荐系统：召回 → DeepFM 排序 → 5 步混排 → 降级 → 服务化 → 真实 CTR 评估 + 偏差传播诊断

数据说明：本项目全部数据由 src/data/synthetic_generator.py 合成生成（固定随机种子），不使用、也不声称使用任何真实业务数据。 选择合成数据是因为它让「潜在真实 CTR」成为已知量，从而能够构造 Oracle 上界并给出不依赖平滑估计的评估口径，这是本项目量化结论得以成立的前提。 代价是：指标衡量的是方法在受控条件下的有效性，而非线上可迁移性， 完整局限清单见 README「诚实边界与局限性」。

系统架构

核心链路

多路召回热门兜底 + ItemCF + Two-Tower 向量召回 + 出行规则召回（里程兑换/多段行程），四路融合。
CTR 排序DeepFM（FM + DNN）预估点击率，轻量 LR 预估转化率，多目标打分。
5 步混排复刻工业混排：归一化 → CTR 加权 → 分层排序 → 同品类打散 → 分页去重。
降级兜底CTR 服务异常时退化为历史平均 CTR，保证核心链路不挂。
可解释面板Streamlit 六页、中英双语：推荐演示 / 偏差诊断 / 排序流程 / 真实 CTR 对比 / 模拟 A/B / 模型与验证。
服务化FastAPI 提供 /recommend /explain /ab 接口（含 400/503/500 异常处理）。

点击率 CTR0.5190.618+18.9%（p<0.001）

评估口径透明化：热门基线按「贝叶斯平滑 CTR（α=5）」排序，而日志是随机曝光生成的， 低曝光物品偶被点击就会推高平滑 CTR。完整档实测热门榜 top200 平滑 CTR 0.6231 vs 真实 CTR 0.2528（偏差 +0.37），平滑榜 top10 与真实 top10 仅重合 2/10。 这会使模拟 A/B 中的热门基线被削弱、实验组增益被高估，故结论请以 ② 的真实 CTR 口径为准。
数据为合成（受控实验）；DeepFM / Two-Tower 等均为已有方法的标准实现，本项目不提出新算法、不使用真实业务数据。

④ 研究主线：偏差传播诊断与去偏有效边界

本项目的独有资源是可控 ground-truth，曝光策略自造、propensity 闭式已知，使「去偏估计能否还原真值」可被严格检验。 （完整版见 tech report）

结论一：偏差的主要危害是排序反转，不是水平偏移

曝光偏斜 τ排序级 spearman曝光最少 / 最多KLGini
0.0+0.846632 / 620.01030.0812
1.0+0.622920 / 1040.09440.2464
2.0−0.05160 / 2120.36580.4690
3.0−0.49550 / 2870.68450.6211

spearman 从 +0.8466 一路跌到 −0.4955，在 τ≈2.0 处符号反转，排行榜被搞反了。 只看「平均 CTR 偏高多少」会得出「偏差可控」，却完全看不见排序级的破坏。

结论二：去偏的有效边界由 propensity 动态范围决定，而非偏差强度

实测边界 ESS/N ≈ 0.358：低于该值时 IPS/SNIPS 的方差代价超过纠偏收益，收益转负。 它是本项目给出的唯一可落地判据：只需 propensity 与样本量，不需要 ground-truth； 落地接口 ess_warning_from_log(log, threshold=0.358)。

诚实边界：本实验 propensity 闭式已知，真实系统须估计 propensity，会引入本实验不存在的误差， 实际边界更严苛。可迁移的是方法（用 ESS/N 作预警），不是 0.358 这个数值。

在线部署：训练 / 推理解耦 + 推理基准

免费在线实例内存下限为 690MB。实测「框架基线」：torch + sklearn + numpy + streamlit = 673MB，只剩 16.7MB，必然 OOM； 解耦后 numpy + streamlit = 73MB，留给数据 617MB。故在线侧只加载 numpy 权重，用纯 numpy 复现前向计算，服务期不加载 torch。

指标（micro 档，本机实测）值
冷启动 · 模块导入 / 引擎构造0.21 s / 0.08 s
延迟 · P50 / P990.70 ms / 0.95 ms
吞吐 · 单线程 QPS~1378
峰值内存 · RSS~129 MB（脚本内置断言校验未加载 torch）

PyTorch 与 numpy 前向逐样本等价（最大偏差 1.19e-07），在线演示的仍是同一个已训练模型，只是换了运行时。 基准可复现：python scripts/bench_inference.py --mode micro。

快速开始

pip install -r requirements_full.txt   # 完整依赖（含 torch / sklearn，本地开发与离线复现用）
python -m src.pipeline_demo        # 数据 + 四路召回 + 融合 + 样例推荐
python -m src.eval.evaluate        # LR vs DeepFM AUC + 真实 CTR + Oracle 上界
python -m src.build_online_artifacts micro   # 离线导出 numpy 权重（约 2 分钟）
streamlit run app.py               # 交互式 Demo（默认 micro 档，进程峰值约 297MB）
AEROREC_MODE=lite streamlit run app.py       # 切到 lite 档（约 0.93GB）
uvicorn src.serve.app:app --port 8000        # FastAPI 服务（推荐 / 排序 / A/B）
python -m pytest tests/ -q         # 冒烟测试（107 项）
requirements.txt 只有 numpy + streamlit，是 Streamlit Cloud 的部署专用依赖； 本地开发与离线复现请装 requirements_full.txt。
