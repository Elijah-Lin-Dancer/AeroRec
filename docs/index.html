AeroRec · 出行智能推荐中台

开源、可复现的出行场景智能推荐系统 —— 召回 → DeepFM 排序 → 5 步混排 → 降级 → 真实 CTR 评估

系统架构

核心链路

多路召回热门兜底 + ItemCF + Two-Tower 向量召回 + 出行规则召回（里程兑换/多段行程），四路融合。
CTR 排序DeepFM（FM + DNN）预估点击率，轻量 LR 预估转化率，多目标打分。
5 步混排复刻工业混排：归一化 → CTR 加权 → 分层排序 → 同品类打散 → 分页去重。
降级兜底CTR 服务异常时退化为历史平均 CTR，保证核心链路不挂。
可解释面板Streamlit 三页：推荐演示 / 排序流程 / A/B 报告。
服务化FastAPI 提供 /recommend /explain /ab 接口。

② 可引用结论：真实 CTR 口径 + Oracle 上界

方法平均真实 CTR相对热门占 Oracle 上界
随机（下界参照）0.1652−66.4%23.4%
热门（工业常用基线）0.4922—69.7%
DeepFM + 多目标混排0.6032+22.6%85.4%
Oracle 上界（候选池最优）0.7059+43.4%100%

Oracle 池 = 热门候选 ∪ 规则候选 ∪ 3000 个随机物品，在池内按该用户的真实 CTR 降序取 Top-K。 池必须包含其他方法的结局，否则不构成真正的上界。

③ 参考：模拟在线 A/B（口径受限，仅供形式对照）

指标对照组（热门）实验组（DeepFM+混排）提升
点击率 CTR0.5190.618+18.9%（p<0.001）
转化率（转化/曝光）0.1910.227+18.8%（p<0.001）
评估口径透明化：热门基线按「贝叶斯平滑 CTR（α=5）」排序，而日志是随机曝光生成的， 低曝光物品偶被点击就会推高平滑 CTR。完整档实测热门榜 top200 平滑 CTR 0.6231 vs 真实 CTR 0.2528（偏差 +0.37），平滑榜 top10 与真实 top10 仅重合 2/10。 这会使模拟 A/B 中的热门基线被削弱、实验组增益被高估，故结论请以 ② 的真实 CTR 口径为准。
数据为合成（受控实验）；DeepFM / Two-Tower 等均为已有方法的标准实现，本项目不提出新算法、不使用真实业务数据。
