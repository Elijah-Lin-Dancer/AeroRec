# Demo 视频录制脚本（约 30 秒）

> 用于申请补充材料 / README 演示。建议录屏时开系统麦克风或后期配音。

## 准备

1. 在仓库目录运行 `streamlit run app.py`，等待模型加载完成（约 30 秒）。
2. 准备录屏工具（macOS `⌘⇧5`、Windows `Win+G`、或 OBS）。

## 脚本（30 秒）

| 时间 | 画面 | 台词要点 |
|---|---|---|
| 0–5s | 打开 Streamlit 面板首页 | "这是我做的一个出行推荐中台 AeroRec，端到端可复现。" |
| 5–15s | 切到「推荐演示」，输入一个用户 ID，点生成 | "左边是召回+DeepFM 排序+5 步混排，给任意用户实时出 Top-K 推荐，每项带预估 CTR/CVR。" |
| 15–22s | 切到「排序流程」 | "这里展示 5 步混排的中间过程——归一化、多目标加权、分层、同品类打散、去重，可解释为什么这么排。" |
| 22–30s | 切到「A/B 报告」，点运行 | "模拟 A/B 显示：相比热门基线，点击率提升 18.9%、转化率提升 18.8%，都统计显著。" |

## 收尾

- 导出 mp4（建议 1080p）。
- 上传到仓库 `docs/demo.mp4`，并在 README / 展示页引用。

> 可选：也可用 `docs/index.html`（GitHub Pages 展示页）作为静态替代，含架构图与量化结果，直接给链接即可。
