# AeroRec · 出行智能推荐中台

> 面向出行消费场景（机票 / 酒店 / 商城 / 营销 / 直播）的开源智能推荐中台 Demo。
> 工程化复现工业级推荐链路：**召回 → DeepFM CTR 排序 → 5 步混排 → 降级兜底 → 模拟 A/B**。

本 Space 是 [AeroRec](https://github.com/Elijah-Lin-Dancer/AeroRec) 的**在线交互体验入口**。

## ⚠️ 关于本实例的口径（请先读）

本实例运行的是**轻量档**：**2 万用户 × 2 万物品 × 100 万曝光**
（仓库完整档为 10 万 × 10 万 × 500 万），目的是把内存压到在线实例可承受的范围。

因此：

- 本实例**仅用于交互体验**（点选用户、查看推荐、观察混排过程）。
- **本实例的 A/B 数值不可引用。** 原因见下：
  热门基线按「历史日志的平滑 CTR」排序，而本项目日志是**随机曝光**生成的，
  曝光次数少的物品一旦偶然被点击，平滑 CTR 就会被显著高估。
  这属于推荐系统中的**位置偏差 / 数据稀疏偏差**。
- **量化结论一律以完整档离线复现为准**（见仓库 README 与 `docs/index.html`）。

## 三个页面

| 页面 | 内容 |
|---|---|
| 推荐演示 | 选用户 → 出 Top-K 推荐，每项带预估 CTR / CVR 与基础分 |
| 排序流程 | 展示 5 步混排的中间态：归一化 → 多目标加权 → 分层 → 同品类打散 → 去重 |
| A/B 报告 | 对照（热门）vs 实验（DeepFM+混排）的模拟在线 A/B，含显著性检验与口径说明 |

## 技术栈

- **召回**：热门兜底 / 规则召回（里程兑换、零库存、常驻地、多程返程）
- **排序**：DeepFM（FM 一阶 + 二阶交叉 + DNN，PyTorch）做 CTR；LR 做 CVR，多目标加权
- **混排**：归一化 → 加权 → 分层排序 → 同品类打散 → 去重截断
- **降级**：CTR 预估异常 → 回退物品历史平均 CTR
- **评估**：离线 AUC 对比 + 模拟在线 A/B（两比例 z 检验）

## 诚实边界

- 数据为本项目**合成**（受控实验），不使用、也不声称使用任何真实业务数据。
- 生成公式中注入了隐式非线性交叉项（价格敏感×低价、商务×早班机、里程契合），
  模型只能拿到原始特征，交叉需自行学习——此为受控实验设置。
- 模型均使用**已有方法的实现**，本项目**不提出新算法**。
- 实习经历仅作为项目动机来源，实习中未涉及深度排序模型的训练。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py                     # 默认 lite 档
AEROREC_MODE=full streamlit run app.py   # 完整档（10万×10万×500万，需较大内存）
```
